# 《爱情公寓》五季全

## 一、资源介绍

《爱情公寓》（iPartment）是由韦正执导，汪远、韦正、邹杰担任编剧，娄艺潇、陈赫、孙艺洲、李金铭等主演的都市爱情情景喜剧系列。该剧以上海某栋公寓为背景，围绕一群身份、理想各异的青年租客展开，讲述了他们相互陪伴、共同成长的欢乐故事。全系列共五季 124 集，于 2009 年至 2020 年播出，陪伴了一代人的青春岁月。

### 1.1 第一季（2009 年）

- **集数**：20 集
- **主要剧情**：一栋并不奢华的公寓中，七位性格迥异的青年男女因一场婚礼意外相聚。性格泼辣的「大姐大」胡一菲、敏感专一的老好人曾小贤、风流倜傥的花花公子吕子乔、古灵精怪的宅女陈美嘉、单纯善良的天才少年陆展博、爱幻想的富家小姐林宛瑜，以及来自日本的漫画家关谷神奇，从此开启了充满欢笑与温情的合租生活。

### 1.2 第二季（2011 年）

- **集数**：20 集
- **主要剧情**：部分角色离开后，张伟、唐悠悠等新成员加入。本季延续轻松搞笑的风格，讲述了大家在公寓中的日常趣事，同时埋下了许多情感伏笔。张伟的「倒霉」属性和唐悠悠的「戏精」特质为剧集增添了不少笑料。

### 1.3 第三季（2012 年）

- **集数**：24 集
- **主要剧情**：陆展博和林宛瑜回归，关谷神奇与唐悠悠的感情逐渐升温。本季剧情更加紧凑，笑点密集，同时也深入探讨了爱情与友情的主题。胡一菲与曾小贤之间的感情纠葛愈发明显，成为观众关注的焦点。

### 1.4 第四季（2014 年）

- **集数**：24 集
- **主要剧情**：吕子乔与陈美嘉的关系出现转机，曾小贤面临感情抉择。本季依旧保持高水准的喜剧效果，各种脑洞大开的剧情令人捧腹。结尾留下了多个悬念，让观众对下一季充满期待。

### 1.5 第五季（2020 年）

- **集数**：36 集
- **主要剧情**：最终季中，老住客们纷纷修成正果——曾小贤与胡一菲领证结婚，吕子乔成长为有担当的丈夫和父亲，陈美嘉收获安稳家庭。诸葛大力、赵海棠、咖喱酱等新角色加入，带来了新观念和新玩法。本季融入歌舞元素和互动剧形式，以一场盛大的婚礼圆满收官，为整个系列画上句号。

### 1.6 剧集亮点

- **经典角色**：胡一菲的霸气、曾小贤的「好男人」、吕子乔的花心、陈美嘉的呆萌、张伟的「最有种」，每个角色都深入人心。
- **密集笑点**：各种梗和搞笑桥段层出不穷，每集都能让人捧腹大笑。
- **青春回忆**：从 2009 年到 2020 年，陪伴了一代人的成长，成为许多人青春的代名词。
- **创新形式**：第五季融入歌舞、互动剧、弹幕空间等新颖形式，展现了剧组的诚意。
