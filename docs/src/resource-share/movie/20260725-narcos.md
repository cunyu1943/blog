# 《毒枭》三季全

## 一、资源介绍

Netflix 出品的真实事件改编犯罪传记剧，以哥伦比亚可卡因产业为核心，双线并行展现贩毒集团的兴衰与美国 DEA 探员的缉毒博弈。

### 1.1 第一季（2015）：麦德林集团崛起

时间线横跨 20 世纪 70 年代末至 1992 年。原本靠走私起家的巴勃罗・埃斯科瓦尔切入可卡因贸易，联合奥乔亚兄弟等势力组建麦德林集团，垄断全美可卡因供应链，迅速跻身福布斯全球富豪榜前列。他一边以 “贫民罗宾汉” 的形象在麦德林修建住房、医院收买底层民心，一边试图跻身政坛，却因毒枭身份曝光与哥伦比亚政府彻底决裂。

与此同时，美国 DEA 探员史蒂夫・墨菲与哈维尔・潘那入驻哥伦比亚，联手当地力量追查麦德林集团，双方爆发多轮血腥冲突。季末，巴勃罗与政府达成协议入住自建的豪华监狱 “大教堂”，随即又越狱出逃，彻底与官方撕破脸。

### 1.2 第二季（2016）：麦德林集团陨落

承接越狱剧情，逃亡中的巴勃罗持续以恐怖爆炸、暗杀政要等极端手段对抗政府与缉毒力量，但其残暴无度的作风逐渐失去民心，盟友接连倒戈，集团内部分崩离析。墨菲、潘那联合哥伦比亚搜捕部队与民间准军事组织 “洛斯・佩佩斯” 步步紧逼，不断压缩巴勃罗的生存空间。

季终，1993 年巴勃罗在麦德林居民区被搜捕队击毙，横行十余年的麦德林集团彻底覆灭，墨菲也选择离开哥伦比亚。

### 1.3 第三季（2017）：卡利集团的兴衰

巴勃罗死后，行事低调、走企业化路线的卡利集团迅速填补市场空白，成为全球最大的贩毒网络。集团由吉尔伯托・罗德里格斯等四巨头掌控，摒弃麦德林集团的暴力路线，深度渗透政界与商界，以更隐蔽的方式运营全球毒品生意。

哈维尔・潘那留在哥伦比亚主导缉毒行动，面对保护伞更庞大、行事更狡猾的对手，他不得不在规则灰色地带周旋，联合各方力量渗透集团内部。最终季中，卡利集团核心头目相继落网，庞大的贩毒帝国崩塌，潘那也因行动中的灰色操作选择离职。
