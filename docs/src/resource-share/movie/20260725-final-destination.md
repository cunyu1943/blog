# 《死神来了》六部全

## 一、资源介绍

《死神来了》（Final Destination）系列是美国经典恐怖电影系列，自 2000 年首部问世以来，以其独特的「死亡不可逃避」设定、创意爆棚的死亡场景设计和对宿命主题的深刻探讨，成为恐怖片领域难以逾越的里程碑。全系列共六部，每部以一场重大灾难开篇，主角凭借预见能力带领部分人逃脱，但死神会按既定名单逐个取走幸存者的生命。

### 1.1 第一部（2000 年）

- **导演**：黄毅瑜
- **灾难场景**：180 航班空难
- **主要剧情**：高中生亚历克斯在登机前预见航班将在空中爆炸，他的惊慌举动使自己和几位同学被迫离开飞机，成功避开灾难。然而，短暂的幸存只是序曲，死神开始按照既定名单，以各种匪夷所思却又合乎逻辑的方式，逐个取走幸存者的生命。
- **经典死亡场景**：浴室晾衣绳勒颈、公交车撞击等。

### 1.2 第二部（2003 年）

- **导演**：大卫·R·艾里斯
- **灾难场景**：高速公路连环车祸
- **主要剧情**：年轻女孩金伯莉预见连环车祸，救下一群人后发现，幸存者与第一部空难死者存在千丝万缕的联系。第一部唯一幸存者克莉尔协助破解死亡诅咒，但最终仍被死神带走。金伯莉在片尾以「假死」方式骗过死神得以幸存。
- **经典死亡场景**：牙科手术、电梯事故等。

### 1.3 第三部（2006 年）

- **灾难场景**：游乐园过山车事故
- **主要剧情**：温蒂预见过山车事故，带领朋友逃脱。不同于前两部留下幸存者，从第三部开始启动「团灭模式」，无人能逃过死神的追杀。
- **经典死亡场景**：室内日光机火化、游乐场设施事故等。

### 1.4 第四部（2009 年）

- **导演**：大卫·R·艾里斯
- **灾难场景**：赛车场爆炸
- **主要剧情**：恰逢 3D 电影高潮，影片侧重点放在设计具有视觉冲击感的灾难场景上，剧情相对模式化。
- **经典死亡场景**：游泳池排水口吸内脏、赛车事故等。

### 1.5 第五部（2011 年）

- **导演**：史蒂文·奎里
- **灾难场景**：吊桥坍塌
- **主要剧情**：山姆预见吊桥坍塌，带领同事逃脱。本片提出新规则：杀死他人可以夺取其剩余寿命，导致主角团从互助组变成大逃杀。结尾几位幸存者登上 180 航班，与第一部形成时间闭环。
- **经典死亡场景**：激光眼科手术、针灸馆事故等。

### 1.6 第六部（血脉诅咒，2025 年）

- **导演**：亚当·B·斯坦 / 扎克·利波夫斯基
- **灾难场景**：1969 年摩天楼餐厅倒塌
- **主要剧情**：时隔 14 年重启的续作，女主角斯蒂芬妮的祖母在 1969 年预见餐厅倒塌并警告众人，拯救大量生命却扰乱了死神的设计，引发代际诅咒——死神开始系统性清除那些本不该存在的整个家族血脉。本片揭示验尸官布拉德沃斯的真实身份，他正是当年餐厅事件的幸存者。
- **全球票房**：2.85 亿美元，烂番茄新鲜度 92%，成为系列最佳口碑之作。

该系列将日常生活中的普通物品和场景转化为致命陷阱，让观众在观影后忍不住观察四周，寻找潜在危险，这种「日常生活安全宣传片」式的惊悚体验，成为《死神来了》系列最独特的魅力。
