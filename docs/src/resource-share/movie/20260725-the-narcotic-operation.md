# 《扫毒风暴》

## 一、资源介绍

《扫毒风暴》是由五百执导，段奕宏、秦昊领衔主演的禁毒题材电视剧。该剧以 20 世纪 90 年代边境禁毒斗争为背景，跳出「爽感至上」的类型套路，用纪实性镜头语言勾勒出正邪博弈的残酷图景，在追逃较量中深挖人性褶皱与时代印记。全剧共 33 集，豆瓣评分高达 8.0 分，央视八套收视率一度突破 2%，累计播放量达 4.81 亿次。

### 1.1 剧情简介

故事始于 1995 年的西港，以缉毒警察林强峰（段奕宏 饰）调任追查线索为明线，以走私商人卢少骅（秦昊 饰）堕入制贩毒深渊为暗线，同步牵扯出境外海洛因旧线、新型冰毒制贩新线两条分支。林强峰从边境卧底回到西港，凭借敏锐的洞察力和线人网络，逐渐摸清本地毒贩的关系脉络。而卢少骅从化工厂保卫科职员起步，凭借化学天赋和狠辣手段，逐步掌控庞大的毒品网络，成为林强峰最棘手的对手。

### 1.2 人物介绍

- **林强峰（段奕宏 饰）**：经验丰富的缉毒警察，带着卧底战友牺牲之痛重返岗位。他破案方式不拘一格，看似吊儿郎当，实则心思缜密。面对战友牺牲的愧疚与毒贩的步步紧逼，他在痛苦与坚定中不断成长。

- **卢少骅（秦昊 饰）**：化学天才，从化工厂保卫科职员逐步堕落为制毒巨头。他以「好丈夫」「好徒弟」的完美形象潜伏多年，实则心狠手辣、精于算计。他利用体制内身份优势和强大的情报网，多次操控局势、借刀杀人，是林强峰最强大的敌人。

### 1.3 剧集亮点

- **纪实风格**：影片摒弃华丽滤镜，以偏蓝绿的色调还原南方边境小城的阴冷潮湿，大量手持镜头的运用将缉毒行动的生死时速直抵人心。

- **多线叙事**：四条线索相互缠绕、层层递进，从村镇派出所所长到年轻缉毒警，从制贩毒头目到受牵连的普通家庭，群像式刻画让影片超越单纯的警匪故事。

- **立体人物**：打破「英雄无软肋」「反派全脸谱」的刻板设定，将角色置于人性的灰色地带反复拉扯，展现缉毒警的真实与毒贩堕落的完整轨迹。

### 1.4 结局与评价

大结局中，林强峰带队发起突袭，终于抓获卢少骅。然而，在追踪新的贩毒案时，林强峰为保护群众牺牲。卢少骅面对死刑判决，仍坚持「制毒是艺术，吸毒是自由」，彻底撕下伪善面具。该剧被观众评价为「近年来最敢拍的禁毒剧」，真实还原了缉毒干警面临的双重考验——暴力威胁与金钱诱惑，让观众深刻理解「岁月静好」背后，是无数缉毒干警在暗夜中逆行的坚守。
