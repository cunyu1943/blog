# 《白夜追凶》两季全

## 一、资源介绍

《白夜追凶》系列是由王伟、刘英剑执导，指纹编剧，潘粤明领衔主演的中国首部硬汉派悬疑推理剧。该系列以双胞胎兄弟互换身份查案为核心设定，讲述了刑警关宏峰与被卷入灭门惨案的弟弟关宏宇，携手追查真相、对抗犯罪组织的故事。全系列共两季，第一季于 2017 年首播，豆瓣评分高达 8.9 分（70 万人打分）；第二季《白夜破晓》于 2024 年回归，豆瓣评分 6.7 分。

### 1.1 第一季（2017 年）

- **集数**：32 集
- **导演**：王伟
- **主要剧情**：刑警关宏峰（潘粤明 饰）与武警关宏宇（潘粤明 饰）是一对双胞胎兄弟。弟弟关宏宇被卷入一场灭门惨案，成为通缉犯。身为刑侦支队长的哥哥关宏峰坚信弟弟无辜，却因亲属回避原则无法参与调查，愤而辞职。代支队长周巡（王泷正 饰）邀请关宏峰以「编外顾问」身份继续参与重案调查。然而，哥哥关宏峰患有「黑暗恐惧症」，于是兄弟俩白天黑夜共用同一身份，一边侦破各大案件，一边寻找机会调阅灭门案卷宗。

### 1.2 第二季（白夜破晓，2024 年）

- **集数**：29 集
- **导演**：刘英剑
- **主要剧情**：第一季结尾，关宏宇顶替哥哥入狱。第二季紧接这一情节展开，关宏峰继续追查 2·13 灭门案真相。本季引入新角色刑钊，引出掌控中津昆仑的裴家易，最终揭露幕后真凶是已退休的施局施广陵。剧中，刘音为救关宏峰挡枪下线，关宏峰在与施局的最终对决中被勒死后焚尸。关宏宇以关宏峰的身份回到长丰支队，为哥哥扫墓时留下「哥你好好休息吧」的遗言。

### 1.3 剧集亮点

- **潘粤明一人分饰四角**：潘粤明凭借精湛演技，将沉稳内敛的哥哥关宏峰、张扬外放的弟弟关宏宇，以及「假扮哥哥的弟弟」「假扮弟弟的哥哥」四种状态演绎得淋漓尽致。
- **严谨的推理逻辑**：全剧采用单元剧形式，每个案件都紧扣主线灭门惨案，层层递进，抽丝剥茧。
- **美剧质感**：精致的片头设计、紧凑的叙事节奏、冷峻的视觉风格，展现出媲美美剧的制作水准。

### 1.4 获奖与影响力

- 第一季上线仅 3 周播放量突破 5.5 亿，最终以超过 40 亿播放量收官
- 2017 年被 Netflix 买下海外发行权，在全球 190 多个国家和地区播出，成为首部正式在海外大范围播出的中国网络剧集
- 第一季荣获 2017 横店影视节「最佳网络剧奖」、微博年度热剧奖等多项荣誉
