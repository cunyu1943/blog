# 《暗黑》三季全

## 一、资源介绍

《暗黑》（Dark）是由巴伦·博·欧达尔执导，巴伦·博·欧达尔、扬特耶·弗里泽编剧的德国科幻悬疑剧，也是 Netflix 首部德语原创剧。该剧以德国小镇温登为背景，通过复杂的时间旅行设定和多线叙事，探讨命运、自由意志与因果循环等深刻主题。全系列共三季 26 集，于 2017 年至 2020 年播出，豆瓣评分第一季 9.0 分、第二季 8.6 分、第三季 9.2 分，被誉为「烧脑神剧」。

### 1.1 第一季（2017 年）

- **集数**：10 集
- **主要剧情**：德国小镇温登，少年米克尔突然失踪，引发警方调查。随着调查深入，小镇核电厂地下的神秘洞穴浮出水面——这里存在连接不同时空的虫洞。故事在 1953 年、1986 年、2019 年三条时间线间切换，四个家族三代人的秘密逐渐揭开。主角乔纳斯·卡恩瓦尔德在父亲自杀后，逐渐卷入时间旅行的漩涡，发现一切早已命中注定。

### 1.2 第二季（2019 年）

- **集数**：8 集
- **主要剧情**：时间线扩展至 1921 年和 2053 年，五条时间线并行叙事。乔纳斯穿越到未来，目睹世界毁灭的惨状，决心改变过去。剧中人物关系网愈发复杂，角色之间的血缘关系和因果联系令人震惊。时间在这部剧里不是线性的，而是一个循环——过去决定未来，未来也决定过去。

### 1.3 第三季（2020 年）

- **集数**：8 集
- **主要剧情**：最终季引入两个平行世界——亚当的世界和夏娃的世界。乔纳斯和玛莎跨越两个世界，试图打破时间循环。剧中揭示了循环的起源：钟表匠创造时光机却未能救回家人，意外分裂出两个平行宇宙。最终结局中，循环被打破，所有因时间旅行产生的人物和事件都归于虚无，回归到一个没有时间旅行的「本源世界」。

### 1.4 剧集亮点

- **复杂的时间线叙事**：五条时间线并行，伏笔埋整季，逻辑严丝合缝，需要观众全神贯注甚至反复观看。
- **深刻的哲学探讨**：探讨自由意志是否存在、一切是否早已注定等问题，结局即是开端。
- **出色的配乐**：Apparat 的《Goodbye》等配乐与剧集调性完美契合，营造出压抑而神秘的氛围。
- **完美闭环**：主创从第一季就规划好了三季大纲，结局不烂尾，逻辑完美闭环。
