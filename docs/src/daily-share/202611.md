## 1101

1. [Filee](https://github.com/KnifeLemon/Filee)

用拖放操作的免费开源文件格式转换器。按住一个键（Ctrl，macOS 为 Option）拖动文件，光标处会弹出格式圆环，放到想要的格式上即可。

2. [纪录片库](https://jilupianwang.com)

一个按题材整理的纪录片网站。搜索中文片名、英文名和别名，按年份与出品方筛选纪录片；查看片目资料、主题片单、夸克等网盘分享，以及央视网、NFB 等观看网站入口。

## 1102

1. [OpenIDEA](https://github.com/l0ng-ai/openidea)

基于 Rust 重构，这款高性能原生应用拥有 IntelliJ IDEA 风格的快捷键映射、工具窗口和全局搜索功能：内置编辑器、代码智能提示、调试器、Git、终端、数据库客户端与 HTTP 客户端，支持 60 余种编程语言。

2. [Oleafly](https://github.com/Oleafly/Oleafly)

一款功能强大的编辑器，用于以 LaTeX、Typst 和 Markdown 撰写研究论文和学位论文。一个项目的源文件、PDF、引文、图形、检查和 Git 历史都集中在一处。与合作者实时写作，让项目在多台电脑之间保持同步，并把 Claude Code、Codex 或你喜欢的任何模型带进项目。

## 1103

1. [第一性原理大模型课程](https://github.com/zhuangzhaoyeye/llm_course)

写给算法工程师的大模型课程：34 课，每课从一个问题出发，用具体数字把机制从头算一遍。

2. [拍片哥女装 · AI 服装参考图集](https://github.com/paipiange/nvzhuang)

一个深色主题的纯净服装参考图集网站，收录 1407 张 人物不入镜的 AI 生成服装图像（2:3 比例），支持中英文双语浏览、多维检索，并配备可选的 AI 一键换装试穿。

## 1104

1. [Free Library](https://github.com/cunyu1943/free-library)

一个专注于收集和推荐免费电子书下载网站的开源项目。项目整理了 Z-Library、Anna's Archive 等主流免费电子书镜像站点的可用链接，并通过自动化手段持续检测各站点可达性，帮助你快速找到当前可访问的免费电子书资源。

2. [墨观 Inkstone](https://github.com/Konata9/inkstone)

一套从 526 个中国传统颜色 里长出来的代码配色。墨纸组（玄墨 / 宣纸 + Dimmed）与海瓷组（沧海 / 青瓷）共六个变体，共用同一套色相骨架。
